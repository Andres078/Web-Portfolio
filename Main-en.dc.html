P-01DIGITAL IC · TEAM PROJECT

Transistor-level 1:4 FIR interpolation filter

A 6-bit interpolation filter built transistor by transistor, from logic gates up to the full system. It uses a polyphase architecture for speed, with a balanced pipeline and an optimized critical path.

// DESIGN CHOICES

The zero-stuffed samples are never stored or computed, which saves flip-flops and lets operations run in parallel. Multiplications are resolved in the routing, with no hardware multipliers.

// VERIFICATION

Parameterized testbenches with digital bus stimuli and impulse response. Stable at 427.35 MHz; fails at 429.18 MHz. Clock and select lines need strong buffers.

P-03ASIC

LCD controller on silicon · Tiny Tapeout

A digital IC written in Verilog and submitted for fabrication through Tiny Tapeout. It drives a fixed message to a 16×2 LCD using the 4-bit parallel mode, sending each byte as two nibbles. Built in a single day with the Tiny Tapeout flow and open-source tools.

P-04EMBEDDED · TEAM

Autonomous exploration vehicle

Capstone project: a differential-drive vehicle built from scratch. A single ESP32 runs the control loop (PID or LQR) and obstacle avoidance from its sensors. It is driven from a Firebase web page that also serves as the vehicle's dashboard.

Motion sensor using WiFi CSI

Motion detection from WiFi channel state information (CSI). An ESP32 XIAO with external antennas captures CSI from a network whose router keeps a constant stream of traffic, and a Raspberry Pi processes the signals.
